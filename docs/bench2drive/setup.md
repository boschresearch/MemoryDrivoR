# Bench2Drive Setup

Run commands from the repository root unless a command changes directory.

## Environment Variables

Set these once in each shell:

```bash
export MEMORYDRIVOR_ROOT="$(pwd)"
export BENCH2DRIVE_DEVKIT_ROOT="$MEMORYDRIVOR_ROOT/bench2drive"
export Bench2Drive_ROOT="$BENCH2DRIVE_DEVKIT_ROOT/Bench2Drive"
export Bench2DriveZoo_ROOT="$BENCH2DRIVE_DEVKIT_ROOT/Bench2DriveZoo"
export B2D_DATA_ROOT="$Bench2DriveZoo_ROOT/data/bench2drive"
export B2D_ARCHIVE_ROOT="$B2D_DATA_ROOT/archives"
export CARLA_ROOT="$MEMORYDRIVOR_ROOT/carla"
export OPENSCENE_DATA_ROOT="$MEMORYDRIVOR_ROOT/dataset"
export NAVSIM_EXP_ROOT="$MEMORYDRIVOR_ROOT/exp"
export HYDRA_FULL_ERROR=1
export PYTHONPATH="$BENCH2DRIVE_DEVKIT_ROOT:$Bench2DriveZoo_ROOT${PYTHONPATH:+:$PYTHONPATH}"

# For closed-loop evaluation:
export LEADERBOARD_ROOT="$Bench2Drive_ROOT/leaderboard"
export SCENARIO_RUNNER_ROOT="$Bench2Drive_ROOT/scenario_runner"
export PYTHONPATH="$LEADERBOARD_ROOT:$SCENARIO_RUNNER_ROOT:$CARLA_ROOT/PythonAPI/carla${PYTHONPATH:+:$PYTHONPATH}"
```

## Repository Layout

Create local folders:

```bash
mkdir -p \
  "$MEMORYDRIVOR_ROOT/exp" \
  "$MEMORYDRIVOR_ROOT/carla" \
  "$MEMORYDRIVOR_ROOT/weights/original_ckpts" \
  "$MEMORYDRIVOR_ROOT/weights/vit_small_patch14_reg4_dinov2.lvd142m" \
  "$MEMORYDRIVOR_ROOT/memory_banks"
```

Clone Bench2Drive repositories under `bench2drive/`:

```bash
cd "$BENCH2DRIVE_DEVKIT_ROOT"

git clone https://github.com/Thinklab-SJTU/Bench2Drive.git Bench2Drive
git -C Bench2Drive checkout 2645714eb1f3a100217928dd113093cae0779f36

git clone --branch uniad/vad https://github.com/Thinklab-SJTU/Bench2DriveZoo.git Bench2DriveZoo
git -C Bench2DriveZoo checkout 498c1f799dd90faf840dedb3f0d3234ec2e567db

mkdir -p "$BENCH2DRIVE_DEVKIT_ROOT/Bench2DriveZoo/data/bench2drive"
```

Expected structure:

```text
MemoryDrivoR/
|-- docs/
|-- bench2drive/
|   |-- ...
|   |-- Bench2Drive/     # cloned repository
|   `-- Bench2DriveZoo/  # cloned repository
|-- carla/          # local CARLA simulator
|-- exp/            # local caches, logs, and evaluations
|-- weights/        # local checkpoints
`-- memory_banks/   # local memory-bank files
```

## Download Data

Review the Bench2Drive and CARLA licenses before downloading. Skip this section
for released closed-loop evaluation. Download the Full sets only if you want to
regenerate the memory bank.

```bash
conda activate memorydrivor-b2d

mkdir -p \
  "$B2D_ARCHIVE_ROOT/base" \
  "$B2D_ARCHIVE_ROOT/full" \
  "$B2D_ARCHIVE_ROOT/full_sup" \
  "$B2D_DATA_ROOT/v1" \
  "$B2D_DATA_ROOT/maps"

# Base routes are delivered as one .tar.gz archive per route. Keep the
# archives separate; all preprocessing code reads the extracted v1/ tree.
huggingface-cli download --repo-type dataset --resume-download \
  rethinklab/Bench2Drive \
  --local-dir "$B2D_ARCHIVE_ROOT/base"

find "$B2D_ARCHIVE_ROOT/base" -type f -name '*.tar.gz' \
  -exec tar -xzf '{}' -C "$B2D_DATA_ROOT/v1" \;

# HD maps are not bundled with the route archives, but prepare_B2D.py requires
# them at $B2D_DATA_ROOT/maps.
huggingface-cli download --repo-type dataset --resume-download \
  rethinklab/Bench2Drive-Map \
  --local-dir "$B2D_DATA_ROOT/maps"
```

Required input layout before Base-set preprocessing:

```text
bench2drive/Bench2DriveZoo/data/
|-- bench2drive/
|   |-- v1/
|   |   |-- Accident_Town03_Route101_Weather23/
|   |   `-- ...
|   `-- maps/
|       |-- Town01_HD_map.npz
|       `-- ...
`-- splits/
    `-- bench2drive_base_train_val_split.json
```

`data/infos/` is generated by the preprocessing step; do not create it in
advance.

## Generate Metadata, Cache, And Map

```bash
conda activate memorydrivor-b2d

cd "$Bench2DriveZoo_ROOT/mmcv/datasets"
python prepare_B2D.py --workers 32
```

This creates:

```text
bench2drive/Bench2DriveZoo/data/infos/
|-- b2d_infos_train.pkl
|-- b2d_infos_val.pkl
`-- b2d_map_infos.pkl
```

Build the DrivoR cache:

```bash
cd "$BENCH2DRIVE_DEVKIT_ROOT"

python navsim/planning/script/run_b2d_dataset_caching.py \
  --cache-path "$NAVSIM_EXP_ROOT/B2d_cache" \
  --data-root "$Bench2DriveZoo_ROOT/data/bench2drive" \
  --map-file "$Bench2DriveZoo_ROOT/data/infos/b2d_map_infos.pkl" \
  --num-workers 32 \
  --prefetch-factor 1
```

Generate the CARLA lane-marking map:

```bash
python navsim/planning/script/run_b2d_gen_mapinfo.py \
  --output-path "$NAVSIM_EXP_ROOT/map.pkl" \
  --graphics-adapter 0 \
  --startup-timeout 60 \
  --use-wrapper
```

## (Optional) Memory bank regeneration

For memory-bank regeneration, download the Full and Full-Sup data of Bench2Drive (total size:  4 TB):
```bash
huggingface-cli download --repo-type dataset --resume-download \
  rethinklab/Bench2Drive-Full \
  --local-dir "$B2D_ARCHIVE_ROOT/full"

huggingface-cli download --repo-type dataset --resume-download \
  rethinklab/Bench2Drive-Full-Sup \
  --local-dir "$B2D_ARCHIVE_ROOT/full_sup"
```
Then route archives them into the same `$B2D_DATA_ROOT/v1` tree, then generate Full-set metadata
shards. The preprocessor treats every route outside the Base validation split
as training data, which is the intended Full + Base-partial source set.
```bash
find "$B2D_ARCHIVE_ROOT/full" "$B2D_ARCHIVE_ROOT/full_sup" \
  -type f -name '*.tar.gz' -exec tar -xzf '{}' -C "$B2D_DATA_ROOT/v1" \;

cd "$Bench2DriveZoo_ROOT/mmcv/datasets"

mv -T "$Bench2DriveZoo_ROOT/data/infos" "$Bench2DriveZoo_ROOT/data/infos-base"
python prepare_B2D.py --workers 32 --tmp_dir tmp_data
mv -T "$Bench2DriveZoo_ROOT/data/infos" "$Bench2DriveZoo_ROOT/data/infos-full+base-partial"
mv -T "$Bench2DriveZoo_ROOT/data/infos-base" "$Bench2DriveZoo_ROOT/data/infos"
```

The memory-bank builder uses the shard files matching
`bench2drive/Bench2DriveZoo/data/infos-full+base-partial/tmp_data/b2d_infos_train_*.pkl`.
